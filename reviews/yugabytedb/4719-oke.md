# YugabyteDB on OKE (Oracle Cloud Kubernetes)

- Original: [published 2021-09-03](https://www.yugabyte.com/blog/yugabytedb-on-oke-oracle-cloud-kubernetes/)
- Review cutoff: 2026-03-06
- Status: `verified-no-change`
- Evidence: documentation only; no deployment test

## What was reviewed

The article describes deploying YugabyteDB on Oracle Kubernetes Engine and connecting through the PostgreSQL-compatible YSQL endpoint.

## Finding

The deployment mechanism remains applicable. Current YugabyteDB documentation supports Kubernetes deployment with Helm; cloud pricing and free-tier allowances are time-sensitive and should always be checked separately rather than treated as a database guarantee.

## Evidence

- [YugabyteDB Kubernetes deployment](https://docs.yugabyte.com/stable/deploy/kubernetes/)
- [Oracle Kubernetes Engine pricing](https://www.oracle.com/cloud/cloud-native/container-engine-kubernetes/pricing/)

## Companion update

The Kubernetes deployment model in this 2021 article remains valid for YugabyteDB 2025.2. Current YugabyteDB documentation continues to provide Helm-based Kubernetes deployment paths. Oracle Cloud prices and free-tier limits are commercial terms, so verify those separately before reproducing the cost assumptions.
